2. classify
    2-1. mac 점수를 인자로 받아서 Cross | X | UNDECIDED 중 하나를 결정하는 함수입니다.
        => 두 점수는 입력 데이터가 얼마나 필터와 가까운가의 점수 -> 높으면 가까움
    2-2. 프로그래밍에서 부동소수점 비교
        => 부동 소수점은 십진수 값을 메모리에 정확하게 저장 못하는 경우가 많기 때문에 ==로 비교하면 위험합니다.
        => 컴퓨터가 정수 5는 0101로 표현가능
        => 0.1를 2진수로 바꾸면 0.000110011001100110011... 처럼 무한히 반복됩니다.
        => 즉, 0.1를 컴퓨터가 저장할 떄 무한을 저장할 수 없으니까 어느 지점에서 잘라야 합니다.
        => 따라서 실제 메모리에는 0.1과 아주 가까운 값이 저장됩니다.
        => 만약 두 부동소수점을 ==으로 비교하면 메모리에 저장된 값은 비슷한 값이라 false가 나올 수 있습니다.
        => 그래서 EPSILON을 사용합니다. -> 허용 오차
