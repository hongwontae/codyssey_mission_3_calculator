1. def input_matrix() 설명
    1-1. 처음에는 [] 빈 리스트를 matrix라는 이름에 할당합니다.
    1-2. for i in range(3)
        => 3번의 입력을 받겠다는 의미입니다.
        => i는 0,1,2를 나타냅니다.
    1-3. split()
        => 문자열을 여러 조각으로 나누고 리스트 안에 넣습니다.
        => split 인자가 없으면 공백으로 처리합니다.
        => "Hello World".split() -> ["Hello", "World"]
    1-4. map(함수, 반복 가능한 객체)
        => 반복 가능한 객체를 받아서 각 요소에 지정한 함수를 적용합니다.
        => map의 결과는 바로 리스트가 아닙니다. -> map 객체입니다.
    1-5. list(반복 가능한 객체)
        => 반복 가능한 객체를 받아서 그 요소들을 담은 새로운 리스트를 반환합니다.
    1-6. row = list(map(int, input(f"{i + 1}번째 행: ").split()))
        => input() 1번 쨰 행에서 입력을 받고 공백을 기준으로 리스트로 만듭니다.
        => map(int, 리스트)를 통해 int 자료형으로 만듭니다.
        => map 객체를 list화 합니다.
    
    1-7. 숫자가 정확히 3개인지 확인합니다.
        => if len(row) != 3 -> print() + continue
    1-8. 숫자가 0 | 1인지 확인합니다.
        => in 연산자 -> 값 in 반복 가능한 객체 -> 값이 반복 가능한 객체에 존재하면 True, 그렇지 않으면 False
        => not in -> 어떤 값이 안에 들어있지 않은지 확인합니다.
        => any -> 반복 가능한 객체를 받아서 여러 개 값 중 하나라도 True라면 True
        => any가 제너레이터 표현식을 하나씩 받아서 처리할 수 도 있습니다.
    
    1-9. 하나의 행이 검증이 끝나면 matrix.append를 통해 리스트 2차원 리스트로 들어갑니다.
        => 2차원 배열
        => 그리고 break
        => 그리고 그 다음 배열 -> 2차원 배열..
