1. if __name__ == "__main__" :
        main()
    1-1. 터미널에서 python main.py 실행
    1-2. 파이썬이 내부적으로 main.py의 특별한 변수인 __name__에 "__main__"이라는 값을 넣어줍니다.
    1-3. __name__이 "__main__"이라면 파일 이름이 아니고 직접 실행된 파일이라는 의미를 가집니다. 
    1-4. 만약 다른 파일에서 import main를 가져와서 __name__을 print하면 그 파일이름 자체가 나옵니다. -> (main)


2. main() 실행 흐름
    2-1. 모드를 선택하라는 출력문이 나옵니다.
    2-2. input를 통해 선택을 받습니다. -> "1"과 "2"가 아니라면 다시 입력을 받습니다.
        => 1이라면 사용자 입력를 받아서 패턴를 분석합니다.
        => 2라면 data.json을 분석합니다.
    2-3. "0"이라면 프로그램을 종료합니다. -> break;
    2-4. 잘못된 입력을 받으면 While문 흐름으로 다시 입력을 받습니다.
    2-5. ctrl + c / ctrl + d -> 예외처리로 프로그램을 종료합니다.
