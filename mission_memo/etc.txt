1. 맥북 캡쳐 단축키
    1-1. command + shift + 3 : 전체 화면을 캡쳐
    1-2. command + shift +4 : 원하는 화면만 캡쳐


2. 과제에서 말하고자 하는 것
    2-1. 숫자 배열을 이용해서 이 패턴이 Cross인지, X인지 판단하는 프로그램을 만들어라 -> 이게 과제의 목표입니다.
    2-2. 컴퓨터가 어떻게 Cross, x 같다고 판단?
        => Cross나 x 필터를 만듭니다.
        => 그리고 사용자 입력을 받고 두 배열의 같은 위치를 곱하고 더합니다.
        => 그러면 점수가 더 높은 필터가 존재 -> 이 판단이 MAC 연산입니다.
    2-3. MAC 연산은 각 위치를 곱하고 전부 더하는 연산입니다.
    2-4. NPU 시뮬레이터 -> 행렬과 텐서 연산을 수행하는 것을 말함 -> 과제에서는 Python으로 아주 단순화한 NPU의 MAC 연산을 흉내내보자는 것
    2-5. 입력의 크기가 3*3 = 9 / 5*5 = 25 / 25*25 = 625.. -> 시간 복잡도가 O(N^2)가 됩니다.
