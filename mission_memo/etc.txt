2. 과제에서 말하고자 하는 것
    2-1. 숫자 배열을 이용해서 이 패턴이 Cross인지, X인지 판단하는 프로그램을 만들어라 -> 이게 과제의 목표입니다.
    2-2. 컴퓨터가 어떻게 Cross, x 같다고 판단?
        => Cross나 x 필터를 만듭니다.
        => 그리고 사용자 입력을 받고 두 배열의 같은 위치를 곱하고 더합니다.
        => 그러면 점수가 더 높은 필터가 존재 -> 이 판단이 MAC 연산입니다.
    2-3. MAC 연산은 각 위치를 곱하고 전부 더하는 연산입니다.
    2-4. NPU 시뮬레이터 -> 행렬과 텐서 연산을 수행하는 것을 말함 -> 과제에서는 Python으로 아주 단순화한 NPU의 MAC 연산을 흉내내보자는 것
    2-5. 입력의 크기가 3*3 = 9 / 5*5 = 25 / 25*25 = 625.. -> 시간 복잡도가 O(N^2)가 됩니다.

4. MAC(Multiply-Accumulate) 연산이 무엇이고, AI에서 왜 중요한지 설명할 수 있다.
    => 입력과 필터가 존재할 떄 같은 위치를 곱하고 누산하는 연산입니다.
    => AI 신경망에서는 이러한 mac 연산을 반복합니다.
    => AI가 사진을 본다 -> 이 이미지에서 선이 있는지, 모서리가 있는지, 곡선이 있는지.. 같은 특징을 찾기 위해 수많은 가중치와 입력을 곱하고 더합니다.
    => 사진 -> input_data / 선 검출 필터, 모서리 검출 필터, 곡선 검출 필터 -> filter_data
5. data.json의 “키 규칙/라벨 규칙”을 해석하고, 프로그램 내부에서 라벨을 표준화(정규화)하는 이유를 설명할 수 있다.
    => JSON에서 사용하는 표현과 프로그램 내부에서 사용하는 표현을 통일하기 위해서입니다.
6. 크기별 연산 시간을 측정하고, 패턴 크기 증가에 따른 시간 복잡도 O(N²)를 근거와 함께 설명할 수 있다.
    => 이중 for문의 인자값이 size -> 외부 for이 한 번 돌 떄 내부 for이 다 도는 구조입니다.
    => size가 10이라면 -> case1 (10), case2 (10)... case10 (10) -> 10*10 -> 10^2
